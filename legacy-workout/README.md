# ארכיון — מעקב אימונים

הגרסה הקודמת של האתר (Workout Tracker 2.0), נשמרה כמו שהיא כשהריפו עבר לשמש
את אפליקציית **מדריך הפסנתר** שבשורש.

לא בוצע בה שום שינוי — רק הועברה לתיקייה. היא עדיין עובדת:
פותחים את `index.html` כאן, או `<כתובת האתר>/legacy-workout/`.

ההיסטוריה המלאה שלה נשמרה ב-git (`git log --follow legacy-workout/script.js`).
