# 🎹 מדריך פסנתר — Piano Guide

אפליקציית ווב שמראה לך **אילו קלידים לנגן**, על מקלדת פסנתר לרוחב המסך.
מניחים את הטלפון על מעמד התווים של הפסנתר האמיתי, בוחרים יצירה — והתווים "נופלים" אל הקליד הנכון.

---

## הרעיון: איך "שמים תווים" בפועל

זיהוי אוטומטי של **תמונת** דף תווים (OMR) הוא בעיה קשה ולא אמינה. במקום זה האפליקציה עובדת עם
הפורמטים שבהם התווים כבר מקודדים דיגיטלית — ולכמעט כל יצירה מוכרת הם קיימים בחינם:

| מקור | פורמט | איפה משיגים |
|---|---|---|
| קובץ MIDI | `.mid` / `.midi` | piano-midi.de, Mutopia, MuseScore |
| תווים דיגיטליים | `.musicxml` / `.mxl` / `.xml` | MuseScore.com (ייצוא), Sibelius, Finale, IMSLP |
| הקלדה ידנית | טקסט קצר | בתוך האפליקציה — `E4 E4 F4 G4 \| G4 F4 E4 D4` |

שלושתם מתורגמים לאותו מבנה פנימי אחד: רשימת תווים `{זמן, משך, גובה, יד}`.
משם כל השאר — ציור, השמעה, מצב תרגול — עובד בדיוק אותו דבר.

---

## מה יש באפליקציה

* **מסלול תווים נופלים** מעל המקלדת — כתום = יד ימין, כחול = יד שמאל. כשהמלבן נוגע בקו התחתון, מנגנים.
* **מקלדת מדויקת** עם גיאומטריה אמיתית של קלידים שחורים, סימון `C4` בכתום כנקודת התמצאות מול הפסנתר האמיתי.
* **שני מצבי תרגול:**
  * **עוקב** — הזמן רץ לפי הטמפו, אתה מתלווה.
  * **המתן לי** — הנגינה נעצרת על כל תו/אקורד עד שתנגן אותו. הקלט יכול להגיע מ:
    * מגע במסך,
    * פסנתר חשמלי דרך **Web MIDI**,
    * **מיקרופון** — זיהוי גובה צליל בזמן אמת (אוטוקורלציה), לפסנתר אקוסטי. מונופוני, לתרגול מלודיה.
* **שליטה בקצב** — מהירות 25%–150%, טמפו (BPM) ידני, ספירה לתוך היצירה, מטרונום.
* **בידוד יד** — שתי ידיים / ימין / שמאל.
* **לולאת תרגול** — קביעת נקודת התחלה וסוף וחזרה אינסופית על התיבות הקשות.
* **טווח קלידים** — אוטומטי לפי היצירה, או הרחבה/הצרה/הזזה ידנית באוקטבות.
* **שמות תווים** — C D E או דו רה מי או בלי.
* **עובד אופליין** (Service Worker), שומר הגדרות ויצירות שיובאו, ומונע כיבוי מסך בזמן נגינה.

## הספרייה המובנית (נחלת הכלל)

כוכב קטן · המנון לשמחה · מנואט בסול מז'ור (פצולד) · לאליזה · פרלוד בדו מז'ור BWV 846 ·
קאנון ברה · סונטת אור הירח פרק 1 — קטעי פתיחה, חלקם בעיבוד מפושט.

## ארכיטקטורה

```
├── index.html          שלד + ממשק (עברית, RTL)
├── css/app.css
└── js/
    ├── main.js         הדבקה: מצב, ממשק, לולאת האנימציה
    ├── notation.js     מודל התו, המרות שמות, פרסר הטקסט הקומפקטי
    ├── songs.js        הספרייה המובנית
    ├── midi.js         פרסר Standard MIDI File (פורמט 0/1) כולל מפת טמפו
    ├── musicxml.js     פרסר MusicXML + פתיחת .mxl דחוס (DecompressionStream)
    ├── player.js       טרנספורט: ביטים↔שניות, מצב "המתן לי", לולאה, מטרונום
    ├── render.js       גיאומטריית קלידים + כל הציור על Canvas אחד
    ├── audio.js        סינתיסייזר פסנתר (Web Audio, הרמוניות + מעטפת)
    ├── input.js        Web MIDI + זיהוי גובה צליל מהמיקרופון
    └── store.js        localStorage
```

**החלטות תכנון:**

* **קנבס אחד** למסלול התווים ולמקלדת יחד — כך המלבן הנופל תמיד מיושר פיקסלית עם הקליד שמתחתיו.
* **הזמן נמדד בביטים**, לא בשניות. המרה לשניות עוברת דרך מפת טמפו (`beat → sec`), כך ששינוי מהירות
  או קובץ MIDI עם ריטרדנדו עובדים נכון, וקווי התיבות תמיד במקום.
* **בלי תלויות ובלי שלב בנייה** — ES Modules טהורים. אפשר להעלות את התיקייה כמו שהיא לכל שרת סטטי.

**פורמט הטקסט להקלדה ידנית**

```
C4          תו (C4 = דו מרכזי)      F#3 / Bb2   דיאז / במול
C4+E4+G4    אקורד                    C4:2        משך בביטים (ברירת מחדל 1 = רבע)
r:1         הפסקה                    ( C4 E4 )*4 חזרה
C4@1        אצבע                     |           מפריד תיבות (מתעלמים ממנו)
```

### אייפון / אייפד — מה שונה

בתוך האפליקציה יש **"תאימות המכשיר הזה"** שבודק בזמן אמת מה נתמך בדפדפן שלך. בקצרה:

| נושא | מצב ב-iOS | מה עושים |
|---|---|---|
| Web MIDI (פסנתר חשמלי) | ❌ ספארי לא מממש את ה-API, וכל הדפדפנים ב-iOS הם ספארי מתחת למכסה | מיקרופון או מגע. פסנתר MIDI דורש אפליקציה נייטיב |
| מיקרופון | ✅ מעל https, אחרי לחיצה | GitHub Pages זה https — עובד |
| מסך מלא (Fullscreen API) | ❌ באייפון (באייפד כן) | "הוספה למסך הבית" נותן את אותו אפקט |
| נעילת כיוון לרוחב | ❌ `orientation.lock` ו-`orientation` במניפסט מתעלמים | לסובב ידנית + לכבות נעילת סיבוב במרכז הבקרה |
| מסך שנשאר דלוק | ✅ מ-iOS 16.4 (Wake Lock) | בגרסה ישנה: הגדרות ← תצוגה ← נעילה אוטומטית ← לעולם לא |
| שמירת יצירות | ⚠️ ספארי מוחק אחסון אתרים אחרי ~7 ימים ללא שימוש | להוסיף למסך הבית, ולגבות דרך "ייצוא לקובץ" |
| מתג ההשתקה | ⚠️ עלול להשתיק את הצליל של האפליקציה | לכבות את מתג ההשתקה, או פשוט לנגן בלי צליל |
| בורר הקבצים | ⚠️ סינון לפי סיומת מאפיר קבצי MIDI | האפליקציה מזהה iOS ומורידה את הסינון |

הפריסה מתחשבת ב-`safe-area` — המגרעת בצד והפס התחתון לא חותכים את הקלידים, וצביטה לזום חסומה
כדי שהמקלדת לא תזוז מתחת לאצבע.

## מגבלות ידועות ומה אפשר להוסיף

* זיהוי המיקרופון הוא **מונופוני** — מזהה תו אחד בכל רגע, לא אקורדים. לאקורדים צריך פסנתר MIDI.
  שיפור אפשרי: NMF/CQT או מודל קטן לזיהוי פוליפוני.
* אין עדיין **ניקוד/דיוק** (כמה תווים פגעת, איפה נתקעת) — קל להוסיף מעל `player.userNote`.
* אין **אצבוע אוטומטי**; השדה `finger` קיים במודל ומצויר, אבל צריך למלא אותו (ידנית או באלגוריתם).
* צילום דף תווים ← תווים (OMR) לא נתמך. אם זה יידרש — לשלוח לשירות חיצוני ולקבל MusicXML.
* קבצי MIDI מורכבים (פדאל, מספר כלים) מיובאים כתווים בלבד; חלוקת הידיים נעשית לפי רצועה/ערוץ,
  ואם אין — לפי גובה (מעל/מתחת ל-C4).
